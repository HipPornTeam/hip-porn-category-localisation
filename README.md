# hip.porn category localisation dataset

This repository contains a snapshot of the category labels used across the nine live language versions of hip.porn.

- 151 matched categories
- English, German, Spanish, Portuguese, French, Polish, Turkish, Ukrainian and Russian
- one stable category ID and URL slug per row
- localized labels and public category URLs for every language

The labels reflect the site's current navigation. Some are adapted for local usage or search language, so they should not be treated as literal dictionary translations.

## Files

- `multilingual-category-glossary.csv` — the complete 151-row dataset
- `README.md` — scope and field notes

## Source

The canonical, searchable reference is the [hip.porn category localisation page](https://www.hip.porn/resources/category-localisation).

Snapshot date: 2026-11-14. The CSV contains terminology for an adults-only website but no images or video.
